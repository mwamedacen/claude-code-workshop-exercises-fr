### 3. Four questions, four short answers · 10 min

> Delegate four independent questions to `analyste-donnees` in parallel. (1) What share of room bookings had no check-in, and which rooms stand out? (2) How many large rooms were booked for one or two people? (3) What is desk occupancy by weekday, and do colleagues stay in their team's zone? (4) At what time do booking errors cluster, and how many people click “Ajouter à mon agenda (bientôt)”? For each answer, give the unit, numerator, denominator, calculation rule, and what the number does not prove. Do not paste raw rows.

**While Claude works:** predict a useful chart for each question. **Check:** four separate answers, each with a caveat. Repeat clicks and distinct people are different units.

### 4. A reproducible notebook · 10 min

> Create `analytics/septembre.ipynb` with four charts for those questions. Read SQLite in read-only mode; keep calculations and labels in the notebook. Begin by printing the number of rows in `bookings`. Execute every cell using the repo's Python environment, then tell me whether it ran and how many charts it produced. Do not commit a database copy or bulky outputs.

In VS Code, you can select the `.venv` kernel and run cells one by one. In a terminal, ask Claude to use `jupyter nbconvert --execute` through the Python environment in `.venv` (its path differs by system).

**Check:** all four charts have titles and understandable denominators, with no execution error.

### 5. A control number · 5 min

The first count can mislead. The expected number of **distinct bookings** is **1,671**.

> Find out why the row count differs from 1,671. Show a deduplication rule I can explain, its effect on at least two charts, then rerun the notebook. Do not delete rows from the source database.

**Check:** the notebook reaches 1,671 without changing SQLite. If it does not, leave the discrepancy visible and investigate the deduplication key.

Run `/compact` with “Keep the four aggregated results, their denominators, the deduplication rule, and the files created; discard intermediate output,” then run `/context`.
