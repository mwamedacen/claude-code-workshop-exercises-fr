# Atelier 1 · Les boutons manquants (35 min)

*Après le bloc 1 : la boucle explorer → agir → vérifier, les modes Plan/Manual/Auto, les demandes d'autorisation, `Esc`, `/rewind` et `/usage`.*

**Mission.** Ma Place affiche le plan des locaux, mais ses principaux boutons manquent. Demandez à Claude de trouver ce que le code sait déjà faire, puis rendez quatre actions accessibles à l'écran.

**Départ.** Votre repo fraîchement cloné est au point `w1-depart`. Si vous restez bloqué, `npm run checkpoint -- w2-depart` sauvegarde votre travail et vous conduit au résultat de référence de cet atelier.

**Règle pendant la formation.** Si Claude repère un défaut, notez-le sans le corriger. Vous étudierez les défauts à l'atelier 2.

## Parcours principal · 28 min

### 1. Ouvrir l'application · 3 min

À la racine du repo, lancez `npm start` et ouvrez l'adresse affichée. Démarrez Claude Code dans le même dossier (`claude`, ou l'extension VS Code). Lors de la première demande de confiance, vérifiez qu'il s'agit bien de **votre copie du repo de formation** avant d'accepter.

**Vérifiez :** le plan du troisième étage apparaît ; cliquer sur un poste ou une salle affiche ses détails ; aucun bouton ne permet de réserver. Regardez le mode indiqué sous la saisie de Claude. Le mode initial dépend de votre configuration.

### 2. Explorer en plan mode · 5 min

Appuyez sur `Shift+Tab` jusqu'à voir « plan mode on », puis demandez :

> Que sait déjà faire cette application ? Quelles fonctions existent dans le code sans bouton à l'écran ? Ne modifie aucun fichier.

**Pendant la réponse :** prédisez les fichiers que Claude lira. **Vérifiez :** aucun fichier n'a changé ; Claude trouve quatre actions sans bouton : « Réserver », « Mes réservations », « Annuler » et « Je suis arrivé·e ». A-t-il trouvé une cinquième fonction ?

### 3. La cinquième fonction · 2 min

> La fonction d'export que tu as trouvée devrait-elle avoir un bouton ? Quelles données contient-elle ?

**Vérifiez :** l'export contient des noms et des adresses e-mail. Notez-le : cela deviendra une règle du projet à l'atelier 3. N'ajoutez pas de bouton d'export.

### 4. Un bouton en Manual mode · 7 min

Appuyez sur `Shift+Tab` jusqu'à voir « manual mode on ». Claude peut proposer de corriger d'autres défauts ; gardez-les pour l'atelier 2.

> Ajoute un bouton « Réserver » aux détails d'un poste et d'une salle disponibles, en réutilisant la fonction existante. Ne corrige rien d'autre : les défauts sont pour l'atelier 2.

Lisez chaque demande d'autorisation : le fichier et le diff pour une modification, la commande exacte pour Bash, ou le serveur et l'action pour un outil MCP. Si une action n'est pas claire, refusez-la et demandez une explication à Claude.

**Vérifiez :** rechargez la page et réservez un poste libre ; le plan l'indique « à vous ». Expliquez ce que chaque autorisation acceptée a permis.

### 5. Les trois autres boutons en Auto mode · 6 min

Appuyez sur `Shift+Tab` jusqu'à voir « auto mode on », puis demandez :

> Ajoute « Mes réservations » dans l'en-tête, puis « Annuler » et « Je suis arrivé·e » dans ma liste de réservations. Réutilise les fonctions existantes.

**Pendant la réponse :** prédisez les écrans à examiner. **Vérifiez :** « Mes réservations » affiche vos réservations ; les deux autres actions sont disponibles. Essayez-les et notez tout comportement étrange sans le corriger.

### 6. Interrompre, revenir en arrière, mesurer · 5 min

Demandez par exemple à Claude de « mettre tous les boutons en rose vif », puis appuyez sur `Esc` pendant son travail. Laissez passer une petite modification, lancez `/rewind` et restaurez le code au point précédent. Enfin, lancez `/usage`.

**Vérifiez :** les boutons ont retrouvé leur apparence et vous savez expliquer ce qu'affiche `/usage`. `/rewind` agit dans la session Claude Code ; `npm run checkpoint` change l'état Git du repo. Ce sont deux mécanismes différents.

## À montrer à la fin

- [ ] Les quatre boutons existent et déclenchent une action.
- [ ] Je peux expliquer une demande d'autorisation concernant un fichier, une commande ou un outil.
- [ ] J'ai annulé une modification avec `/rewind`.
- [ ] J'ai noté les comportements à étudier à l'atelier 2.

## Si le groupe prend du retard

Le formateur montre l'étape 6 pendant le débrief. Gardez les quatre boutons et vos notes sur les défauts.
