# Lab 1 · The missing buttons (35 min)

*After block 1: the explore → act → check loop, Plan/Manual/Auto modes, permission requests, `Esc`, `/rewind`, and `/usage`.*

**Mission.** Ma Place shows the floor plan, but its main buttons are missing. Use Claude to find what the code can already do, then make four actions available on screen.

**Start.** Your newly cloned repo is at `w1-depart`. If you get stuck, `npm run checkpoint -- w2-depart` saves your work and takes you to the reference result for this lab.

**Rule for the course.** If Claude notices a defect, write it down without fixing it yet. You will investigate defects in lab 2.

## Core path · 28 min

### 1. Open the app · 3 min

At the repo root, run `npm start` and open the address it prints. Start Claude Code in the same folder (`claude`, or the VS Code extension). When asked to trust the folder for the first time, check that it is **your copy of the course repo** before accepting.

**Check:** the third-floor plan appears; clicking a desk or room opens its details; no button lets you book. Look at the mode under Claude's prompt. Its initial mode depends on your configuration.

### 2. Explore in plan mode · 5 min

Press `Shift+Tab` until the status line says “plan mode on,” then ask:

> What can this app already do? Which functions exist in the code but have no button on screen? Do not change any files.

**While Claude works:** predict which files it will read. **Check:** no files changed; Claude finds four actions without a button: “Réserver,” “Mes réservations,” “Annuler,” and “Je suis arrivé·e.” Did it find a fifth function?

### 3. The fifth function · 2 min

> Should the export you found get a button? What data does it contain?

**Check:** the export contains names and email addresses. Note this: it will become a project rule in lab 3. Do not add an export button.

### 4. One button in Manual mode · 7 min

Press `Shift+Tab` until the status line says “manual mode on.” Claude may offer to fix other defects; save those for lab 2.

> Add a “Réserver” button to the details for an available desk and room, reusing the function that already exists. Fix nothing else; the defects are for lab 2.

Read each permission request: the file and diff for an edit, the exact command for Bash, or the server and action for an MCP tool. If an action is unclear, decline it and ask Claude to explain.

**Check:** reload the page and book a free desk; the plan marks it “à vous.” Explain what each permission you accepted allowed.

### 5. The other three buttons in Auto mode · 6 min

Press `Shift+Tab` until the status line says “auto mode on,” then ask:

> Add “Mes réservations” to the header, then “Annuler” and “Je suis arrivé·e” to my bookings list. Reuse the existing functions.

**While Claude works:** predict the screens you will inspect. **Check:** “Mes réservations” shows your bookings; the other two actions are available. Try them and note any strange behavior without fixing it.

### 6. Interrupt, rewind, measure · 5 min

For example, ask Claude to “Make every button bright pink,” then press `Esc` while it works. Let a small change through, run `/rewind`, and restore the code from the previous point. Finally, run `/usage`.

**Check:** the buttons have their earlier appearance, and you can explain what `/usage` displays. `/rewind` acts within a Claude Code session; `npm run checkpoint` changes the repo's Git state. They serve different purposes.

## Show at the end

- [ ] All four buttons exist and perform an action.
- [ ] I can explain a file, command, or tool permission request that I saw.
- [ ] I undid a change with `/rewind`.
- [ ] I noted behaviors to investigate in lab 2.

## If the group runs late

The trainer demonstrates step 6 in the debrief. Keep the four buttons and your notes about defects.
